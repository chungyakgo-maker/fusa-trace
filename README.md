# FuSa Trace

기능안전 산출물(FSR → TSR → FMEA → SSR/HSR → 시험)의 추적성과, DIA 기준 산출물 일정·작성 현황을
한눈에 보여 주는 **오프라인 Windows 앱**입니다. 업데이트 확인 말고는 인터넷에 연결하지 않고, 관리자 권한 없이 설치됩니다.

## 설치 파일 받기

**Releases** 페이지(오른쪽 메뉴)에서 최신 버전을 열고, 아래 중 **하나만** 받으면 됩니다.

| 파일 | 설명 |
|---|---|
| `FuSaTrace-<버전>-Setup.exe` | **설치형 (권장)**. 내 계정에만 설치되어 관리자 권한이 필요 없습니다. |
| `FuSaTrace-<버전>-Portable.exe` | 설치 없이 실행합니다. |
| `FuSaTrace-<버전>-win-x64.zip` | 원하는 폴더에 압축을 풀고 `FuSaTrace.exe`를 실행합니다. 위 두 가지가 막힐 때 씁니다. |

- 코드 서명이 없어서 처음 실행할 때 "Windows의 PC 보호" 창이 뜰 수 있습니다 → **추가 정보 → 실행**
- 개발 중인 최신 빌드는 **Actions** 탭 → 가장 위의 초록색 실행 → 아래쪽 **Artifacts**에서 받을 수 있습니다 (GitHub 로그인 필요).
- 설치 위치: `%LOCALAPPDATA%\Programs\fusa-trace` / 데이터: `%APPDATA%\FuSaTrace`
- 지우기: Windows 설정 → 앱 → 설치된 앱 → FuSa Trace → 제거 (데이터 폴더는 남습니다)

## 업데이트 (v0.6.0부터)

- 앱의 **설정 → 업데이트 → [버전 확인]** → 새 버전이 있으면 **[업데이트]**
  - 설치형: 받은 뒤 **[지금 설치하고 다시 시작]** → 조용히 덮어 설치하고 앱이 다시 켜집니다. 프로젝트·데이터는 그대로입니다.
  - 포터블·압축본: 실행 중인 파일은 바꿀 수 없어서 다운로드 폴더에 새 파일을 받아 드립니다. 앱을 닫고 새 파일을 실행하세요.
- 앱을 켤 때 자동으로 확인하고, 새 버전이 있으면 화면 위쪽에 알림이 뜹니다 (설정에서 끌 수 있음).
- 확인·받기를 할 때만 GitHub에 접속합니다. 보내는 것은 앱 버전뿐이고 문서·프로젝트 내용은 보내지 않습니다.
  받은 파일은 Release의 `SHA256SUMS.txt` 확인값과 맞을 때만 씁니다.
- 회사망·보안 프로그램에서 GitHub이 막히면 "연결하지 못했습니다"가 뜹니다. 그때는 위처럼 Releases 페이지에서 받아 설치하면 됩니다 (덮어 설치, 데이터 유지).

## 지금 되는 것 (v0.7.0)

- **산출물 일정** (DIA 엑셀): 산출물별 담당·계획·실적·상태, 간트, VR 작성 O/X, 엑셀 출력 (작성 리스트, 담당자별 요약, 추적성 누락)
- **일정·담당 직접 고치기**: [고치기]로 계획·실적 날짜와 담당을 고치고, 엑셀 출력의 "DIA 붙여넣기" 시트를 원본 DIA의 같은 칸에 값 붙여넣기
- **시스템 추적성** (FSR 엑셀 + TSC 워드): FSR → TSR 연결, 누락·확인 필요·없는 ID 참조·ID 중복
- **연결 지도**: SG → FSR → TSR → FMEA 근거 카드와 선, 카드를 누르면 위·아래 연결 강조 + 상세(출처, 적힌 참조 원문, 해석 방식), 정상 연결은 묶음
- **FMEA 근거** (FMEA 엑셀): TSR별 고장원인 연결, 역방향 확인(ASIL 있는데 TSR 없는 고장원인)
- **소프트웨어 탭** (SRS 워드 + SW 시험 명세): TSR(S/W) → SSR → SW 시험 지도·목록, 역방향 확인
- **하드웨어 탭** (HSR + FMEDA): TSR(H/W) → HSR 연결, 역방향 확인, FMEDA 작성 여부
- **칸 지정**: 처음 보는 양식(HSR·SW 시험 명세)의 칸 역할을 한 번 정하면, 같은 모양의 문서는 자동으로 읽음
- **동의어 편집**: 문서마다 다르게 부르는 칸 이름을 설정에서 추가
- **ID 대응표**: TSC·FMEA·SRS·HSR·SW 시험의 애매한 참조를 한 번 고르면 다음 버전 문서에도 기억
- **문서 관리**: 버전 이력, 가져오기 결과 다시 보기, DIA 산출물 연결 바꾸기
- **업데이트**: 설정에서 버전 확인 → 업데이트, 앱을 켤 때 자동 확인

## 개발 (GitHub Actions에서 자동으로 실행됨)

```
npm ci            패키지 설치
npm run typecheck 타입 검사
npm test          단위 테스트
npm run dist:win  Windows 설치 파일 빌드 (dist/)
npm run smoke     빌드된 앱 실행 확인
```

이 저장소에는 실제 회사 문서·고객사 이름·실제 ID를 올리지 않습니다. 테스트에는 가짜 문서만 씁니다.
